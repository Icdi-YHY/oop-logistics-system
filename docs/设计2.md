# 题目二：快递员任务管理子系统 - 设计文档

## 一、题目二新增功能

| 编号 | 功能 | 说明 |
|------|------|------|
| 1 | 管理快递员 | 管理员添加/删除快递员 |
| 2 | 快递分类 | 易碎品、图书、普通快递，不同计费规则 |
| 3 | 发送快递 | 按类型计费，状态变为待揽收 |
| 4 | 快递员揽收 | 管理员分配快递员，揽收后分成50% |
| 5 | 接收快递 | 用户签收（同题目一） |
| 6 | 快递员查询 | 快递员查询自己的揽收任务 |
| 7 | 管理员增强 | 可查看快递员及其揽收记录 |

## 五、业务流程

### 5.1 发送快递流程

```
1. 用户登录
2. 选择快递类型：
   - 1. 易碎品（8元/kg）
   - 2. 图书（2元/本）
   - 3. 普通快递（5元/kg）
3. 输入收件人用户名
4. 输入物品描述
5. 输入重量/数量
6. 计算价格 = 单价 × 重量/数量
7. 检查余额是否充足
8. 扣费
9. 增加管理员公司余额
10. 生成快递单号
11. 创建对应类型的Package对象（状态=待揽收）
12. 保存到文件
13. 显示成功信息
```

### 5.2 快递员揽收流程

```
【管理员操作】
1. 管理员登录
2. 查看所有待揽收快递
3. 选择快递
4. 选择快递员
5. 分配（快递状态变为待签收，记录courierId）

【快递员操作】
1. 快递员登录
2. 查看分配给自己的待揽收快递
3. 选择揽收
4. 计算金额 = 快递费的50%
5. 管理员公司余额 -= 金额
6. 快递员账户 += 金额
7. 保存数据
8. 显示揽收成功
```

### 5.3 快递员查询流程

```
1. 快递员登录
2. 显示查询菜单：
   - 1. 我揽收的快递
   - 2. 按状态查询
   - 3. 按单号查询
3. 显示结果
```

## 九、对题目一的修改清单

题目二在题目一基础上，需要对以下部分进行修改：

### 9.1 引入 Person 基类（代码复用）

**问题**：User 和 Admin 有大量重复代码

**修改**：

| 操作 | 说明 |
|------|------|
| 新增 `Person.h` / `Person.cpp` | 抽取 User 和 Admin 的共同属性和方法 |
| 修改 `User.h` | `class User : public Person` |
| 修改 `Admin.h` | `class Admin : public Person` |
| 修改 `User.cpp` / `Admin.cpp` | 调用父类构造函数 |

**Person 类属性**：username_, name_, password_, balance_
**Person 类方法**：GetUsername(), GetName(), GetPassword(), GetBalance(), CheckPassword(), SetPassword(), AddBalance(), DeductBalance()

### 9.2 修改 Package 类体系

**问题**：题目一 Package 是简单类，不支持多态计费

**修改**：

| 操作 | 说明 |
|------|------|
| 修改 `Package.h` | 改为抽象基类，添加纯虚函数 `virtual double GetPrice() const = 0` |
| 修改 `Package.cpp` | 实现通用方法，删除计费相关代码 |
| 新增 `FragilePackage.h/.cpp` | 易碎品子类 |
| 新增 `BookPackage.h/.cpp` | 图书子类 |
| 新增 `NormalPackage.h/.cpp` | 普通快递子类 |
| 修改 `packages.txt` 格式 | 增加类型、重量/数量、揽收员ID字段 |

### 9.3 修改 LogisticsSystem 类

**问题**：功能太多，需要拆分和增强

**修改**：

| 操作 | 说明 |
|------|------|

| 新增 `currentCourier_` 属性 | 当前登录的快递员 |
| 新增 `nextCourierId_` 属性 | 快递员ID自增 |
| 新增 `courierLogin()` 方法 | 快递员登录 |

| 新增 `assignCourier()` 方法 | 管理员分配揽收任务 |

| 新增 `courierQuery()` 方法 | 快递员查询任务 |

| 修改 `loadData()` / `saveData()` | 增加 couriers.txt 读写 |
