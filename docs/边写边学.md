# 写的过程中的学习
## 位于类private中的辅助方法是什么？
- 只给类内部自己用的方法，用户不需要知道。
- 避免重复代码

## const成员函数只能调用const成员函数
- const不会修改对象，如果调用了非成员函数就有可能修改了对象

## 类与类之间最好不要互相访问
- 可以通过外观类、控制器类等等实现类之间的控制

## 所有的chioce都用string类型
防止chioce在是整型时非法输入导致错误

如果输入的必须是整型，则要避免非法输入

std::cin >> num;

改为

if(!(std::cin >> num))
{
    std::cin.clear();
    std::cin.ignore(10000,'\n');
    std::cout << "输入非法";
    continue;
}
